Interface Interativa


const TaskApp = () => {
  const [tasks, setTasks] = useState([
    { id: 1, text: 'Estudar React Native', done: false },
    { id: 2, text: 'Fazer exercícios', done: false }
  ]);

  const toggleTask = (id) => {
    setTasks(tasks.map(task =>
      task.id === id ? { ...task, done: !task.done } : task
    ));
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Minha Lista de Tarefas</Text>
      {
        tasks.map(task => (
          <TouchableOpacity
            key={task.id}
            onPress={() => toggleTask(task.id)}
            style={styles.task}
          >
            <Text style={[
              styles.taskText,
              task.done && styles.taskDone
            ]}>
              {task.done ? '✅' : '⭕'} {task.text}
            </Text>
          </TouchableOpacity>
          )
        )
      }
    </View>
  );
};

Atividade

📝 Adicione uma nova tarefa

Complete a aplicação para permitir que o usuário adicione tarefas à lista.

  • Crie um estado novaTarefa para armazenar o texto digitado.
  • Use um TextInput para atualizar esse estado.
  • Ao pressionar o botão Adicionar, inclua um novo objeto em tasks.
  • O novo objeto deve possuir: { id, text, done: false }.
  • Depois de adicionar, limpe o campo de texto.
💡 Utilize setTasks sem alterar diretamente o array original. 

const TaskApp = () => {

  const [tasks, setTasks] = useState([]);
  const [novaTarefa, setNovaTarefa] = useState('');

  const adicionarTarefa = () => {
    const tarefa = {
      id: Date.now(),
      text: novaTarefa,
      done: false
    };

    setTasks([...tasks, tarefa]);
    setNovaTarefa('');
  };

  return (
    <View style={styles.container}>

      <TextInput
        placeholder="Digite uma tarefa"
        value={novaTarefa}
        onChangeText={setNovaTarefa}
      />

      <Button
        title="Adicionar"
        onPress={adicionarTarefa}
      />

      {
        tasks.map(task => (
          <Text key={task.id}>
            • {task.text}
          </Text>
        ))
      }

    </View>
  );
};

novaTarefa controla o campo e tasks mantém a lista de tarefas.

Entendendo a estrutura

Primeiro, a ilustração. Depois, o mesmo Hook dentro de um componente.

02 · Anatomia visual · 1/5

A chamada do Hook

useEffect( effect console.log("Executado"); } , deps ) Efeito · função Dependências

Dois espaços para preencher: o trabalho do efeito e suas dependências.

02 · Anatomia visual · 2/5

O primeiro argumento

useEffect( effect console.log("Executado"); } , deps ) Efeito · função Dependências

effect é uma função. React a executa após o commit; aqui estamos apenas declarando o trabalho.

02 · Anatomia visual · 3/5

O segundo argumento

useEffect( effect console.log("Executado"); } , deps ) Efeito · função Dependências

deps representa uma lista. React compara seus valores para decidir se o efeito precisa executar novamente.

02 · Anatomia visual · 4/5

A função por dentro

useEffect( () => { console.log("Executado"); } , deps ) Efeito · função Dependências

Agora vemos a função: console.log está dentro dela. A lista ainda está representada pelo nome deps.

02 · Anatomia visual · 5/5

Da ilustração ao código

useEffect( () => { console.log("Executado"); } , [] ); Efeito · função Dependências · lista vazia

[] é uma lista vazia. O efeito executa na montagem e não repete por mudanças de props ou estado.

02 · Leitura guiada

As partes do useEffect

useEffect(() => {
  console.log('Efeito:', contador);
}, [contador]);
  • useEffect: Hook importado de react.
  • () => { ... }: função com o trabalho do efeito.
  • [contador]: valores usados para decidir se ele precisa executar novamente.

Chame Hooks no topo do componente, antes de retornos condicionais; nunca dentro de if, loops ou eventos.

Exemplo progressivo

Passo 1: contador com estado

02 · Primeira observação

Passo 2: adicionando o efeito

import { useEffect, useState } from 'react';
import { Button, Text, View } from 'react-native';

export default function Contador() {
  const [contador, setContador] = useState(0);
  useEffect(() => {

Segunda parte · 03

Quando o efeito executa?

Compare as dependências e descubra quando não precisamos de um efeito.

↓ Avance para acompanhar os passos desta subseção.

03 · Dependências

Três formas de declarar

Forma Na montagem Após outros commits
useEffect(fn) Executa Executa a cada commit
useEffect(fn, []) Executa Não repete por mudanças de props/estado
useEffect(fn, [valor]) Executa Repete se valor mudou

React compara cada dependência com o valor anterior usando Object.is. Uma nova montagem inicia um novo efeito.

03 · Dependências

A lista descreve o que o efeito usa

// Trecho dentro de um componente que recebe a prop nome
useEffect(() => {
  console.log(nome, contador);
}, [nome, contador]);

03 · Quando dispensar o efeito

Par ou ímpar é um cálculo

// Trecho dentro do componente Contador
const mensagem = contador % 2 === 0
  ? 'Número par! 👍'
  : 'Número ímpar! 👆';

// Use no JSX: <Text>{mensagem}</Text>

Se o valor pode ser calculado a partir de props ou estado, calcule durante a renderização.

Não precisamos de outro estado nem de um efeito para manter essa mensagem atualizada.

04 · Atividade 1

Construa a mensagem do dia

  • Inicie o estado com “Carregando...”.
  • Ao montar, agende “Bom dia! ☀️” para depois de 2 segundos.
  • Cancele o timeout na função de limpeza.
  • Exiba a mensagem em um Text.

Antes de executar: a mudança da mensagem deve agendar outro timer? Justifique usando as dependências.

Exemplo progressivo

Passo 1: exibir a mensagem inicial

import { useState } from 'react';
import { Text } from 'react-native';

export default function MensagemDoDia() {
  const [mensagem, setMensagem] = useState('Carregando...');

  return <Text>{mensagem}</Text>;
}

Este componente já funciona: por enquanto, a mensagem permanece “Carregando...”.

04 · Solução 1

Passo 2: agendar e limpar o timer

import { useEffect, useState } from 'react';
import { Text } from 'react-native';

export default function MensagemDoDia() {
  const [mensagem, setMensagem] = useState('Carregando...');
  useEffect(() => {
    const timer = setTimeout(() => {
      setMensagem('Bom dia! ☀️');
    }, 2000);
    return () => clearTimeout(timer);
  }, []);

  return <Text>{mensagem}</Text>;
}

O efeito usa apenas um setter estável e valores constantes; por isso, [] é adequado.

04 · Atividade 2

Busque usuários de uma API

Ao abrir a tela, consulte os usuários disponíveis na API:

https://jsonplaceholder.typicode.com/users

  • Crie um estado usuarios iniciado com uma lista vazia.
  • Ao montar o componente, faça uma requisição usando fetch.
  • Converta a resposta para JSON.
  • Salve os dados recebidos no estado usuarios.
  • Renderize o nome de cada usuário usando map.

Antes de executar: qual deve ser o vetor de dependências desse efeito? A alteração de usuarios deve realizar uma nova requisição?

Exemplo progressivo

A estrutura da tela está pronta, mas a lista começa vazia. Ainda precisamos buscar os dados.

04 · Solução 2

Passo 2: buscar e salvar os usuários

import { useEffect, useState } from 'react';
import { Text, View } from 'react-native';

export default function ListaUsuarios() {
  const [usuarios, setUsuarios] = useState([]);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(resposta => resposta.json())
      .then(dados => {
        setUsuarios(dados);
      });
  }, []);

  return (
    <View>
      {usuarios.map(usuario => (
        <Text key={usuario.id}>
          {usuario.name}
        </Text>
      ))}
    </View>
  );
}

[] faz a consulta acontecer na montagem. Quando setUsuarios atualiza o estado, a tela renderiza novamente com os dados recebidos.
