Interface Interativa


const TaskApp = () => {
  const [tasks, setTasks] = useState([
    { id: 1, text: 'Estudar React Native', done: false },
    { id: 2, text: 'Fazer exercícios', done: false }
  ]);

  const toggleTask = (id) => {
    setTasks(tasks.map(task =>
      task.id === id ? { ...task, done: !task.done } : task
    ));
  };

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Minha Lista de Tarefas</Text>
      {
        tasks.map(task => (
          <TouchableOpacity
            key={task.id}
            onPress={() => toggleTask(task.id)}
            style={styles.task}
          >
            <Text style={[
              styles.taskText,
              task.done && styles.taskDone
            ]}>
              {task.done ? '✅' : '⭕'} {task.text}
            </Text>
          </TouchableOpacity>
          )
        )
      }
    </View>
  );
};

O que é useEffect?

É como um "assistente" que nos ajuda a executar ações extras em nossos componentes:

  • 🔄 Executa código quando algo muda
  • 🎬 Roda quando o componente aparece na tela
  • 🧹 Limpa quando o componente some da tela

O Ciclo de Vida com useEffect

🎬 Montagem


useEffect(() => {
  // Roda uma única vez, quando o
  // componente aparece na tela
  buscarDados();
}, []);

🔄 Atualização


useEffect(() => {
  // Roda de novo sempre que
  // 'contador' mudar de valor
  console.log(contador);
}, [contador]);

🧹 Desmontagem


useEffect(() => {
  const id = setInterval(tick, 1000);

  // Roda quando o componente
  // sai da tela
  return () => clearInterval(id);
}, []);

useEffect no Mundo Real 🌍

Alguns cenários comuns onde o useEffect é essencial em apps React Native:

  • 📱 Detectar quando o app volta do segundo plano
  • 🔄 Reagir a mudanças de orientação da tela
  • 📍 Buscar a localização do usuário assim que a tela abre

Detectando o Estado do App


import { AppState } from 'react-native';

const [appState, setAppState] = useState(AppState.currentState);

useEffect(() => {
  const subscription = AppState.addEventListener('change', setAppState);

  return () => subscription.remove();
}, []);

✅ O return remove o listener quando o componente desmonta, evitando vazamento de memória.

Reagindo à Orientação da Tela


import { Dimensions } from 'react-native';

const [isLandscape, setIsLandscape] = useState(false);

useEffect(() => {
  const subscription = Dimensions.addEventListener(
    'change',
    ({ window }) => setIsLandscape(window.width > window.height)
  );

  return () => subscription.remove();
}, []);

Boas Práticas com useEffect ✅

  • 🧹 Sempre limpe timers e subscrições na função de retorno
  • 🎯 Liste no array de dependências tudo que o efeito utiliza
  • ✂️ Separe efeitos por responsabilidade: um efeito, uma tarefa
  • 🔁 Cuidado com loops infinitos ao atualizar estado dentro do efeito
  • 🚫 Evite lógica pesada no efeito quando não for necessário

Resumo da Aula 🔄

  • useEffect executa efeitos colaterais fora do fluxo de renderização
  • O array de dependências controla quando o efeito roda
  • A função de limpeza evita vazamentos de memória
  • É a base para integrar APIs nativas do dispositivo em React Native
